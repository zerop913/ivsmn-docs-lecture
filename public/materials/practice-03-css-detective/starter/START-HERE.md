# Двор: передача проекта

Сайт городских мастерских перед запуском открытой субботы.

1. Распакуйте архив. Не работайте внутри ZIP.
2. Откройте папку в редакторе, а index.html — в браузере.
3. Заявка на восстановление: /web-development/practice-03-css-detective на сайте с заданием.
4. Проверяйте страницу в широком окне браузера — примерно 1280–1440 px.
5. Проверьте и исправьте index.html и styles.css: структуру, переходы, объявления CSS и раскладку.
6. Записывайте причины и выполненные проверки в investigation.md.

Установка зависимостей, сервер и интернет для запуска сайта не нужны.
Все предусмотренные переходы — к разделам этой страницы. Сейчас некоторые из них повреждены или отсутствуют.
Отправка данных, оплата, регистрация, JavaScript и мобильная версия в заявку не входят.

На передачу: исправленные HTML и CSS, журнал, снимки before/after и копия stress-check по заданию.
