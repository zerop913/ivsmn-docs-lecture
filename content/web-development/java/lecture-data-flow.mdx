# Как программа работает с данными

Когда мы открываем приложение, оно что-то считает, проверяет и показывает результат. За этим стоят конкретные инструкции: сохранить значение, сравнить его с другим, повторить действие для каждого элемента. Разберём эти действия на небольших программах Java.

После лекции вы сможете проследить, как меняются переменные, объяснить выбор ветки `if`, пройти по массиву циклом и проверить результат программы на разных данных.

## 1. Как запустить пример

Начнём с полной программы. Сохраните её в файл `Main.java` и запустите в среде разработки:

```java
public class Main {
    public static void main(String[] args) {
        int minutes = 25;
        System.out.println(minutes);
    }
}
```

Программа выведет `25`. Java начинает выполнение с метода `main`, затем выполняет инструкции внутри него по порядку. `int minutes = 25;` создаёт переменную, а `System.out.println(minutes);` выводит её значение и переходит на новую строку.

В каждом следующем примере, если не показан полный класс, помещайте фрагмент **внутрь `main`**. Проверяйте фрагменты по одному: повторное объявление переменной с тем же именем в одном блоке вызовет ошибку.

При запуске из терминала в папке с файлом выполните `javac Main.java`, затем `java Main`. Первая команда компилирует исходный код в байткод, вторая запускает класс в Java Virtual Machine (JVM). Среда разработки выполняет эти шаги за вас.

> Название файла с `public class Main` — именно `Main.java`. Java различает прописные и строчные буквы.

## 2. Переменная, значение и тип

Переменная даёт имя значению, с которым работает программа:

```java
int tasks = 3;
double hours = 1.5;
boolean finished = false;
String title = "Верстка страницы";
```

| Тип | Какие значения используем в примерах | Пример |
|---|---|---|
| `int` | Целые числа | `3`, `-2`, `0` |
| `double` | Числа с дробной частью | `1.5`, `0.25` |
| `boolean` | Логические значения | `true`, `false` |
| `String` | Строки текста | `"Java"`, `"Задача"` |

`String` — класс Java, а не примитивный тип, но для начала удобно пользоваться им как типом текстового значения.

Переменной можно присвоить новое значение. Выражение справа вычисляется **до** присваивания:

```java
int minutes = 20;
minutes = minutes + 10;
System.out.println(minutes); // 30
```

Во второй строке программа берёт старое значение `20`, прибавляет `10` и сохраняет результат `30` в переменную `minutes`. Это инструкция обновить значение, а не утверждение, что число равно самому себе плюс десять.

### Целочисленное деление

```java
System.out.println(7 / 2);     // 3
System.out.println(7 / 2.0);   // 3.5
```

Если оба операнда целые, результат деления тоже целый: дробная часть отбрасывается. Если нужен дробный результат, хотя бы один операнд должен быть дробным. Например, для целых переменных `sum` и `count` можно написать `(double) sum / count`; делить на ноль нельзя.

**Проверьте себя:** чему равны `total` после каждой строки?

```java
int total = 5;
total = total + 3;
total = total * 2;
```

Сначала получите ответ самостоятельно. Затем выведите значение после каждого присваивания и проверьте: должно получиться `5`, `8`, `16`.

## 3. Условие выбирает действие

Представим, что задача считается долгой, если на неё ушло не меньше 30 минут:

```java
int minutes = 35;

if (minutes >= 30) {
    System.out.println("Долгая задача");
} else {
    System.out.println("Короткая задача");
}
```

Выражение `minutes >= 30` имеет значение `true` или `false`. Если оно истинно, выполняется блок после `if`; иначе — блок после `else`. Здесь выведется `Долгая задача`.

| Запись | Значение |
|---|---|
| `a > b` | `a` больше `b` |
| `a >= b` | `a` больше или равно `b` |
| `a < b` | `a` меньше `b` |
| `a <= b` | `a` меньше или равно `b` |
| `a == b` | примитивные значения равны |
| `a != b` | примитивные значения не равны |

`=` присваивает значение, а `==` сравнивает. Для сравнения **содержимого строк** используют `equals`:

```java
String status = "DONE";
if (status.equals("DONE")) {
    System.out.println("Задача выполнена");
}
```

В этом примере `status` содержит строку. Если переменная может быть `null`, безопаснее написать `"DONE".equals(status)`. О ссылках и `null` поговорим подробнее при изучении объектов.

**Проверьте себя:** что программа про длительность выведет при `minutes = 30`? А если заменить `>=` на `>`? Измените значение и проверьте оба варианта.

## 4. Массив: несколько значений под одним именем

Пусть у нас есть время трёх задач:

```java
int[] minutes = {15, 35, 20};
System.out.println(minutes[0]); // 15
System.out.println(minutes[1]); // 35
System.out.println(minutes.length); // 3
```

`int[]` означает массив целых чисел. К элементу обращаются по **индексу**, нумерация начинается с нуля.

| Индекс | `0` | `1` | `2` |
|---|---:|---:|---:|
| Значение | `15` | `35` | `20` |

`minutes.length` — количество элементов, а не последний индекс. При длине `3` последний индекс — `2`. Обращение к `minutes[3]` приведёт к `ArrayIndexOutOfBoundsException` во время выполнения программы.

Элемент можно изменить: `minutes[1] = 40;`. Это меняет второе значение массива, но не его длину.

## 5. Цикл: повторяем действие

Чтобы вывести каждый элемент массива, не обязательно писать отдельный `println` для каждого индекса:

```java
int[] minutes = {15, 35, 20};

for (int i = 0; i < minutes.length; i++) {
    System.out.println(minutes[i]);
}
```

Цикл `for` состоит из трёх частей:

1. `int i = 0` — создаём счётчик перед первой проверкой.
2. `i < minutes.length` — перед каждой итерацией проверяем, можно ли продолжить.
3. `i++` — после тела цикла увеличиваем `i` на единицу.

Для массива длиной три тело выполнится с `i`, равным `0`, `1` и `2`. Когда `i` станет `3`, условие `3 < 3` окажется ложным и цикл завершится.

| Итерация | `i` при входе в тело | `minutes[i]` | Вывод |
|---|---:|---:|---:|
| 1 | 0 | 15 | 15 |
| 2 | 1 | 35 | 35 |
| 3 | 2 | 20 | 20 |

Если в условии ошибочно написать `i <= minutes.length`, при `i = 3` цикл попытается прочитать несуществующий элемент. Важно смотреть не только на условие, но и на то, что происходит **внутри** цикла: именно обращение за пределы массива вызовет исключение.

## 6. Накапливаем результат

Часто цикл нужен не только для вывода. Найдём общую длительность задач:

```java
int[] minutes = {15, 35, 20};
int sum = 0;

for (int i = 0; i < minutes.length; i++) {
    sum = sum + minutes[i];
}

System.out.println(sum); // 70
```

`sum` называется переменной-накопителем: она сохраняет промежуточный результат между итерациями.

| Итерация | Добавляем | `sum` после прибавления |
|---|---:|---:|
| До цикла | — | 0 |
| 1 | 15 | 15 |
| 2 | 35 | 50 |
| 3 | 20 | 70 |

Запись `sum += minutes[i];` означает то же самое, что `sum = sum + minutes[i];`. Важно объявить `sum` **до цикла**: если каждый раз создавать её заново внутри тела, промежуточная сумма не сохранится между итерациями.

## 7. Условие внутри цикла

А теперь посчитаем, сколько задач заняло не меньше 30 минут:

```java
int[] minutes = {15, 35, 20};
int count = 0;

for (int i = 0; i < minutes.length; i++) {
    if (minutes[i] >= 30) {
        count++;
    }
}

System.out.println(count); // 1
```

Цикл перебирает элементы, `if` проверяет каждый из них, а `count` хранит количество подходящих. Для `15` условие ложно; для `35` истинно и счётчик становится `1`; для `20` снова ложно. Запись `count++` увеличивает значение на единицу.

**Попробуйте:** измените условие так, чтобы программа считала задачи длительностью меньше 25 минут. Сначала предположите результат, затем запустите программу. Для исходного массива ответ — `2`.

## 8. Как проверить программу

Один удачный запуск ещё не доказывает, что решение работает для других данных. Для счётчика задач длительностью не меньше 30 минут полезно проверить:

| Данные | Ожидаемое количество | Зачем проверяем |
|---|---:|---|
| `{15, 35, 20}` | 1 | Обычный случай |
| `{5, 10, 20}` | 0 | Нет подходящих элементов |
| `{30, 45}` | 2 | Все подходят; число 30 проверяет границу |
| `{}` | 0 | Нет элементов; цикл не должен выполняться |

Например, пустой массив можно записать так: `int[] minutes = {};`. Приведённый выше счётчик корректно выведет `0`. Но если программа ищет максимум через первый элемент, пустой массив нужно обработать отдельно: у него нет элемента с индексом `0`.

Если результат не совпал с ожиданием:

1. Найдите самые маленькие данные, на которых ошибка повторяется.
2. Проверьте границы условия и цикла.
3. Временно выведите индекс, текущий элемент и промежуточный результат внутри цикла.
4. После исправления повторите все проверки, а не только последнюю.

Ошибка компиляции означает, что Java не смогла собрать программу; исключение при выполнении возникает уже после запуска; логическая ошибка может не показывать сообщение, но давать неверный результат. Сообщение об ошибке и номер строки помогают найти место проблемы, хотя причина иногда находится раньше.
